👗 패턴 두 장을 봉제하기

앞판과 뒷판을 붙였더니 옆선이 벌어졌다. 끝점을 맞추는 대신 "어느 선끼리 붙는지"를 정해 두고 그 선을 기준으로 맞춰 붙여서 해결했다.

seam을 ID 기반 edge pair로 모델링하고, 공통 edge를 기준으로 panel transform을 계산해 사이즈와 무관하게 정합.

🚩 01 · 문제

봉제선이 벌어진다

앞판과 뒷판을 3D로 붙였는데 옆선에서 옷이 벌어져 틈이 보인다.

기술 설명

Front/Back panel mesh 결합 후 side seam 구간에 vertex gap 발생. 렌더 시 틈으로 배경이 보임.

근거: 샘플 — 실제 캡처 없음
🔍 02 · 관찰

끝점이 어긋나 있다

가까이 보니 두 천의 끝이 4mm쯤 어긋나 있었다.

기술 설명

side seam 양 끝 endpoint 간 거리 최대 4.2mm (M 사이즈, 1:1 scale). 중간 구간 vertex 수도 서로 다름 (A 18개 / B 23개).

근거: 샘플 — 실측값 아님
🧪 03 · 시도 1

끝점 억지로 붙이기

가까운 끝점끼리 억지로 붙여 봤다.

기술 설명

seam 후보 endpoint 쌍을 거리 기준으로 찾고 tolerance 5mm 안이면 B의 좌표를 A로 snapping.

근거: 샘플 — 실제 커밋 없음
❌ 04 · 실패

다른 사이즈에서 다시 벌어진다

M 사이즈는 붙었지만 L, XL에서는 다시 벌어졌고, S에서는 엉뚱한 끝점끼리 붙었다.

기술 설명

그레이딩 편차로 endpoint 간 거리가 사이즈마다 달라 고정 tolerance가 맞지 않음. S는 거리가 가까운 다른 edge의 끝점과 잘못 매칭.

근거: 샘플 — 테스트 결과 예시
🧠 05 · 발견

점이 아니라 "선의 짝" 문제

점을 맞추는 문제가 아니었다. 봉제할 때처럼 "이 선과 저 선이 박음질된다"는 짝 정보가 없어서 생긴 문제였다.

기술 설명

원인은 좌표 오차가 아니라 seam relationship 모델 부재. 어떤 edge끼리 결합되는지 정의가 없어 거리 기반 추정에 의존했고, 그레이딩 시 추정이 깨짐.

근거: 샘플
🛠 06 · 해결

봉제선에 이름표 붙이기

봉제선마다 이름표를 붙이고, 같은 이름표끼리 선 전체를 기준으로 맞춰 붙였다.

기술 설명

DXF 로드 시 seam edge에 ID를 부여하고 SeamPair(A.edge, B.edge)로 저장. 결합 시 공통 edge의 시작·끝·방향으로 B panel의 transform을 계산하고, 두 edge를 arc-length 기준으로 같은 개수로 재샘플링.

근거: 샘플 — 실제 커밋 없음
⚠️ 07 · Edge Case

곡선·길이가 다른 봉제선

길이가 다른 곡선 봉제선(예 — 소매산)은 아직 그대로 붙지 않는다. 오그려 박는 여유분 처리가 따로 필요하다.

기술 설명

두 seam edge의 arc-length 차이가 있으면(ease) 균등 재샘플링만으로는 한쪽이 늘어나거나 주름 위치가 틀어짐. ease 분배 규칙은 R-004에서 다룸.

근거: 샘플
✅ 08 · 검증

3종 × 4사이즈 검증

패턴 3종을 사이즈 4개로 붙여 봤고, 12개 모두 벌어지지 않았다.

기술 설명

티셔츠·셔츠·원피스 × S/M/L/XL = 12 case에서 seam gap 0.1mm 이하 확인.
