| 항목 | 내용 |
|---|---|
| 상태 | **채택 — 유일한 출력 스타일** (D13). 엔진: `templates/sketch.html`, 생성: `scripts/render.py` |
| 목업 | [R-001 수작업 목업](../.claude/skills/cobro-recipe/examples/R-001-seam-stitching/mockup.html) · 자동 생성 실례: [cobro-mcp R-001](../examples/cobro-mcp/recipes/R-001-cross-tab-drafts/recipe.html) |
| 참고 | 외부 공개 프롬프트 "아이스 아메리카노 손그림 모션그래픽 명세서" |

## 결론

참고 프롬프트의 **영상 형식이 아니라 렌더 원칙**을 가져와 레시피의 **유일한 출력 형식**으로 쓴다 (초기 clean 스타일은 폐기).

1. `render(t)` 결정적 렌더: 재생·스크롤·재생 막대 어느 쪽으로 t를 바꿔도 같은 그림이 나온다. 스크롤 레시피와 자연스럽게 합쳐진다.
2. 한 장의 모눈종이 + 카메라: 8단계가 **하나의 지도**가 되고, 마지막에 줌아웃하면 전체 과정이 한눈에 보인다.
3. 연필 선 규칙(흔들림 3벌 교대, 진한 선 + 흐린 선, 긋듯 나타남)은 다이어그램보다 "과정"이라는 느낌을 잘 전달한다.
4. 설정 블록(문구·색·시간표·카메라)이 코드 맨 위에 있다 → recipe.yaml → CONFIG 자동 변환(P1 render.py)에 그대로 맞는다.
5. 개발자는 속도(최대 2×)·장면 이동·스크롤로 원하는 곳만 빠르게 보고, 인쇄하면 정적 문서로 나온다 → 스타일 하나로 충분하다.

## 검증: 무엇을 가져오고 무엇을 바꿨나

| 참고 프롬프트 | 판정 | cobro-recipe 적용 |
|---|---|---|
| 세로 1080×1920, 22초 영상 | 변경 | 반응형(가로/세로 자동), 장면 수에 따라 길이 결정(R-001 = 36초) |
| `render(t)` 단일 함수 + 재생 막대 | **채택** | + 스크롤 모드: 스크롤 위치 = t |
| 코드 맨 위 CONFIG | **채택** | recipe.yaml의 scenes → SCENES, 카메라·색은 스타일 기본값 |
| 모눈 연습장 + 가장자리 비네트 | **채택** | 패턴 제도지(모눈) 느낌이라 도메인에 잘 맞음 |
| 연필 선 규칙 (흔들림·겹선·긋기) | **채택** | 동일. `prefers-reduced-motion`이면 흔들림·블러 끔 |
| Gaegu 손글씨, 1초 10칸 쓰기 | **채택** | 오프라인이면 시스템 필기체로 대체. 캡션(설명문)은 가독성을 위해 일반 글꼴 |
| 동그라미 번호 라벨 + 형광 밑줄 | **채택** | 위에 scene 타입(`01 문제`) 표기 추가 |
| 카메라 휙·천천히·확 줌인 + 휙일 때만 모션 블러 | **채택** | '확 줌인'은 `발견` 장면에 고정 배치 (깨달음 강조) |
| 패럴랙스 낙서 층 | 채택 | 커피 낙서 → 단추·시침핀·실·가위표 |
| 주인공 원두 한 알 | **변경** | 주인공은 **도메인 팩이 결정**: `general` = 연필(연필 점선), `garment-3d` = 바늘(실 땀). 배경 낙서도 팩별 |
| 마지막 경로 덧칠 + 라벨 옆 빨간 체크 | 채택 | 미해결 Edge(⑦)는 체크 대신 주황 `?` — 한계를 숨기지 않음 |
| 끝 제목 = 제목 반복 | **변경** | 끝 문장 = **한 줄 교훈** ("봉제선은 점이 아니라 선의 짝") |
| 화면에 숫자 금지 | **변경** | 근거 수치는 허용(4mm, 12/12). 숫자는 레시피의 증거 |
| 설명 텍스트 없음 | **추가** | 하단 캡션에 2층 설명(plain/tech) 동기화 — cobro-recipe 핵심 원칙 유지 |
| 재생·일시정지·막대만 | **추가** | **재생 속도 0.5× ~ 2×**(드롭다운 메뉴, `−`/`+` 키, 마지막 선택 기억), **이전/다음 장면**(⏮ ⏭, `←`/`→` 키) |

## 리스크

| 리스크 | 대응 |
|---|---|
| 장면별 그림을 AI가 매번 그림 → 비용·품질 편차 | scene 타입별 **그림 부품**(패널, 돋보기, 비교 그리드, 매트릭스)을 라이브러리화, AI는 좌표·문구만 채움 (D3 혼합 방식과 동일) |
| 재생이 개발자 참조용으로 느림 | 속도 2×, ⏮⏭ 장면 이동, 스크롤 모드, 인쇄 시 정적 문서 |
| 웹폰트 외부 요청 (Google Fonts) | 선택 사항으로 둠. 오프라인이면 시스템 필기체. 번들하지 않음(3MB, 가벼움 유지) |
| 저사양 PC에서 매 프레임 재그리기 | 현재 도형 수에서는 문제 없음. 장면이 많아지면 화면 밖 장면 그리기 생략 |
